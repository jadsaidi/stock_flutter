# 📦 Stock Flutter - Application SAAS de Gestion de Stock

Application mobile de gestion de stock simplifiée développée en **Flutter**, respectant l'architecture **DDDA** (Domain Driven Design Architecture). 

Design exclusif **"Ultra Quantum"** avec effets de Glassmorphism, néons dynamiques et animations fluides.

---

## 🛠️ Pile Technologique & Architecture
- **Architecture** : DDDA (Domain, Data, Core, Presentation)
- **Routing** : GoRouter
- **State Management** : Riverpod
- **API Client** : Dio
- **Backend / BDD** : Firebase Authentication & Cloud Firestore

## ✨ Fonctionnalités Réalisées (Cahier des charges)
- [x] Authentification par Email/Mot de passe (Firebase Auth).
- [x] Base de données par client isolé (Firestore).
- [x] Gestion des Catégories (Ajout dynamique).
- [x] Gestion des Produits (Ajout par catégorie).
- [x] Gestion des Mouvements (Entrée en stock, Sortie/Vente).
- [x] **Dashboard Analytique Complet** :
  - Filtrage dynamique par plage de date.
  - État du stock (Graphique en barres).
  - Top 3 des produits les plus vendus.
  - Répartition des ventes par catégorie (PieChart).
  - Alertes pour les produits sous le seuil d'approvisionnement.
